# The Movie Vault

A movie discovery app powered by the TMDB API. Users can search for movies, page through results ten at a time, and open a detail page with poster, budget, release date, and overview.

The project focuses on type-safe routing with TanStack Router, Redux Toolkit state, custom pagination logic, and a small SCSS design system with light and dark themes.

## Features

- Search movies through the TMDB API.
- Pagination with ten results per page and API-page calculation.
- Movie detail route with formatted budget and release date.
- Loading placeholders and empty-poster fallbacks.
- Light and dark themes through SCSS variables.
- Type-safe file-based routing with TanStack Router.
- Redux Toolkit slices for movies, loading, and configuration.
- React Compiler enabled through the Vite Babel plugin.

## Getting started

### Requirements

- Node.js 20 or newer.
- npm (a `package-lock.json` is committed).
- A TMDB account and API read-access token.

### 1. Install dependencies

```bash
npm install
cp .env.example .env
```

### 2. Configure environment variables

Create a `.env` file in `movies-pagination/` and add the values below. Use the committed example file as a template when one exists.

```bash
VITE_ACCESS_TOKEN=
```

| Variable | Purpose | Required |
| --- | --- | --- |
| `VITE_ACCESS_TOKEN` | TMDB API v4 read-access token used as a Bearer token. | Yes |

### 3. Run locally

**Start the development server**

```bash
npm run dev
```

Open http://localhost:5173.

Restart Vite after changing `.env`; Vite exposes only `VITE_*` variables.

### Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start Vite on port 5173. |
| `npm run build` | Type-check with `tsc -b` and build for production. |
| `npm run preview` | Preview the production build. |
| `npm run lint` | Run ESLint. |

## How it works

TanStack Router generates `src/routeTree.gen.ts` from `src/routes/`. The root route renders `Layout`; the index route renders the search/list page; `movies/$movieId` renders the detail page.

`useRootHook` owns search and pagination. It stores results, the selected UI page, and the current TMDB API page in Redux, and slices the fetched results into ten-item pages.

`customFetch` builds the URL, attaches the TMDB Bearer token from `import.meta.env`, and returns parsed JSON. `searchMovies` wraps the search endpoint.

`MovieContext` and the `Movie` page component fetch and format a single movie’s details. SCSS variables in `src/styles/` drive the light and dark themes.

## Deployment

- Target: GitHub Actions builds the Vite app and publishes `dist/` to GitHub Pages. Set the Vite `base` to the repository path and add a SPA fallback (for example a copied `404.html`) so deep links work.
- Store `VITE_ACCESS_TOKEN` as a GitHub Actions secret and expose it to the build step. The token is inlined into the client bundle.
- Vercel is a simpler alternative because it handles SPA rewrites automatically.

## Notes and limitations

- The TMDB token is a client-side secret and will be visible in the bundle; restrict it to the minimum required scope.
- `src/routeTree.gen.ts` is generated. Do not edit it by hand; regenerate by running the dev server or build.
- Pagination slices fetched TMDB results into ten-item UI pages and fetches a new API page only when the slice changes.
- The project enables React Compiler through `babel-plugin-react-compiler`; check compatibility before adding older libraries.
